# Systems And Teams Design Docs

This directory documents the phase-1 introduction of `System` and `Team` into the Platform Services Registry.

Files:

-   [PHASE1_SYSTEMS_TEAMS_SPEC.md](/Users/sheaphillips/Development/platform-services-registry/design/PHASE1_SYSTEMS_TEAMS_SPEC.md)
    Design intent, requirements, scope, constraints, and expected behavior.
-   [PHASE1_SYSTEMS_TEAMS_AS_BUILT.md](/Users/sheaphillips/Development/platform-services-registry/design/PHASE1_SYSTEMS_TEAMS_AS_BUILT.md)
    Description of the implementation that was actually built, including important deviations and follow-up notes.

This documentation is intentionally split into:

-   a target-state / requirements-oriented spec
-   an implementation-oriented "as built" record

That separation is important here because phase 1 was explicitly designed to be additive and non-breaking, so the implemented shape is intentionally pragmatic and only partially realizes the longer-term conceptual model.
